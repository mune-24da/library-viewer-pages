ホームプライバシーポリシー利用規約

プライバシーポリシー

ソクミル購入履歴ビューア(以下「本拡張機能」)での、情報の扱いを定めます。制定日: 2026年10月9日。

1. 取り扱う情報

  • ソクミルの購入履歴(作品名、品番、購入日、画質など)と、そこから取得した作品情報。
  • 利用者が付けたお気に入り、備考、手入力した作品情報。
  • Googleドライブとの同期に使う、Googleのアクセストークンと、同期の設定。

2. 保存先

上の情報は、利用者のブラウザ内(拡張機能のローカル保存領域)に保存します。開発者のサーバーはなく、開発者がこれらの情報を受け取ることはありません。

3. Googleドライブの利用

同期機能を有効にした場合のみ、次の権限を使います。

  • 権限: https://www.googleapis.com/auth/drive.appdata(Googleドライブのアプリ専用領域の利用)
  • 用途: 取り込んだデータを暗号化したファイル1つを、この領域に保存し、別のブラウザから読み込むため。
  • データは、利用者が設定した合言葉からAES-GCMで暗号化してから送ります。合言葉を変更していない場合は初期値のままになるため、強く守りたいときは合言葉を変更してください。
  • この領域は本拡張機能からしか見えず、利用者のドライブにある他のファイルは読み書きしません。

本拡張機能によるGoogleのユーザーデータの利用は、Google API Services User Data Policy(限定利用の要件を含む)に従います。

4. 外部サービスへの通信

本拡張機能は、次のサイトに通信します。いずれも、購入履歴や作品情報の取得のためで、利用者の情報を送る目的ではありません。

  • ソクミル(sokmil.com): 購入履歴と商品ページの取得。
  • hopperk.com: 日替わり動画の中身の対応表の取得。
  • FANZA(dmm.co.jp 系): 利用者が作品URLを手入力した作品の、作品情報と画像の取得。
  • Google(googleapis.com、accounts.google.com): ログインとドライブ同期。

5. 第三者への提供

取り扱う情報を、広告、分析、販売などの目的で第三者に提供することはありません。上の外部サービスとの通信を除き、外部に送信しません。

6. データの削除

  • ブラウザから拡張機能を削除すると、ブラウザ内のデータは消えます。
  • Googleドライブ上の同期ファイルは、Googleアカウントの設定(サードパーティ アクセス)から本拡張機能の接続を解除し、アプリのデータを削除することで消せます。

7. 改定

内容を改定するときは、このページを更新します。
