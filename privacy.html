プライバシーポリシー

購入履歴ビューアの拡張機能(ソクミル購入履歴ビューア、FANZA購入済みビューア、MGS動画購入済みビューア、購入履歴 総合ビューア。以下まとめて「本拡張機能」)での、情報の扱いを定めます。どれも同じ作りで、扱う情報と扱い方は共通です。サイトごとに違う点は、その都度書き分けます。購入履歴 総合ビューアは、ほかの3つに取り込んだ作品をまとめて表示するだけで、自分ではどのサイトとも通信しません。

制定日: 2026年10月9日 / 改定日: 2026年10月17日(購入履歴 総合ビューアを対象に加え、5の受け渡しに書き足しました)

1. 取り扱う情報

  • 利用者が購入した作品の一覧と、そこから取得した作品情報。作品名、品番や作品ID、購入日、画質、パッケージ画像のURL、出演者、メーカー、ジャンル、収録時間などです。
  • 利用者が付けたお気に入り、備考、手入力した作品情報、保存した検索条件。
  • Googleドライブとの同期に使う、Googleのアクセストークンと、同期の設定(合言葉、つないでいるGoogleアカウントのメールアドレスと名前、自動で同期するかどうか)。

2. 保存先

上の情報は、利用者のブラウザ内(拡張機能のローカル保存領域)に保存します。拡張機能ごとに別々に保存します。購入履歴や作品情報を拡張機能の間で受け渡すのは、5に書いた購入履歴 総合ビューアへの受け渡しだけです。開発者のサーバーはなく、開発者がこれらの情報を受け取ることはありません。

Googleのアクセストークンは、ブラウザを閉じると消える領域に置きます。

3. Googleドライブの利用

同期機能を有効にした場合のみ、次の権限を使います。

  • 権限: https://www.googleapis.com/auth/drive.appdata(Googleドライブのアプリ専用領域の利用)
  • 用途: 取り込んだデータを暗号化したファイル1つを、この領域に保存し、別のブラウザから読み込むため。ファイルは拡張機能ごとに別です。
  • データは、利用者が設定した合言葉からAES-GCMで暗号化してから送ります。合言葉を変更していない場合は初期値のままになるため、強く守りたいときは合言葉を変更してください。
  • この領域は本拡張機能からしか見えず、利用者のドライブにある他のファイルは読み書きしません。

本拡張機能によるGoogleのユーザーデータの利用は、Google API Services User Data Policy(限定利用の要件を含む)に従います。

4. 外部サービスへの通信

本拡張機能は、次のサイトに通信します。購入済みの一覧、作品情報、再生先は、利用者がそのサイトにログインしている状態のまま、利用者のブラウザから直接取得します。利用者の情報を開発者や第三者に送る目的の通信はありません。

拡張機能通信先目的
ソクミル購入履歴ビューアソクミル(www.sokmil.com、img.sokmil.com)購入履歴、商品ページの作品情報、パッケージ画像の取得。購入履歴のページを開いての再生
FANZA購入済みビューアFANZA(video.dmm.co.jp、api.video.dmm.co.jp、www.dmm.co.jp、画像の配信元)購入済み商品の一覧とパッケージ画像の取得。再生先の取得と、プレーヤーを開くこと
MGS動画購入済みビューアMGS動画(www.mgstage.com、image.mgstage.com)購入済み商品の一覧、購入履歴、商品ページの作品情報、パッケージ画像の取得。プレーヤーを開くこと
3つともGoogle(accounts.google.com、www.googleapis.com、oauth2.googleapis.com)同期機能を有効にした場合の、ログインとドライブ同期

ソクミル購入履歴ビューアでは、利用者が作品情報の手入力で作品URLを入れた場合に限り、次の通信もします。ソクミルの作品URLなら、その作品ページを読み取ります。FANZAの作品URLなら、その作品のパッケージ画像をFANZAの画像の配信元(pics.dmm.co.jp など)から表示します。

5. 同じブラウザに入っている拡張機能との受け渡し

本拡張機能は、同じブラウザに入っている次の拡張機能とだけ、ブラウザの中で情報を受け渡すことがあります。受け渡しは利用者のブラウザの中で完結し、外部には送りません。

  • 本拡張機能どうし: 同期を設定していない拡張機能で、利用者が「(ほかの拡張機能)の同期設定を使って始める」を押した場合に限り、設定済みの拡張機能から、同期の設定(合言葉、Googleアカウントのメールアドレスと名前、自動で同期するかどうか)を受け取ります。購入履歴や作品情報は受け渡しません。
  • 購入履歴 総合ビューア: 利用者が総合ビューアを開いたときに、ほかの3つの拡張機能が、取り込んだ作品の一覧(作品名、購入日、作品情報、お気に入りの印、備考など、画面に表示する内容)を総合ビューアに渡します。総合ビューアは、それを表示するためだけに使います。再生のボタンを押したときは、総合ビューアから、その作品を持っている拡張機能に再生を頼みます。総合ビューア以外の拡張機能からの一覧の依頼には答えません。
  • 開発者が個人用に作った補助の拡張機能: 一般には配布していません。利用者がこれを入れている場合に限り、必要に応じて作品のIDや品番を渡し、作品情報を受け取ります。入れていなければ、この受け渡しは起きません。

6. 第三者への提供

取り扱う情報を、広告、分析、販売などの目的で第三者に提供することはありません。4と5に書いた通信と受け渡しを除き、外部に送信しません。

7. データの削除

  • ブラウザから拡張機能を削除すると、その拡張機能のブラウザ内のデータは消えます。
  • Googleドライブ上の同期ファイルは、Googleアカウントの設定(サードパーティ アクセス)から該当する拡張機能の接続を解除し、アプリのデータを削除することで消せます。
